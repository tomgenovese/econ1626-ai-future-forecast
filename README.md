# Generation is cheap, verification is scarce

An interactive web essay forecasting how AI will reshape Australian financial services to 2030. ECON1626 Assessment 3, RMIT University. Tom Genovese, October 2026.

**Live essay:** https://tomgenovese.github.io/econ1626-ai-future-forecast/forecast.html

## Repository

| File | What it is |
| --- | --- |
| `forecast.html` | The essay |
| `assets/` | Styles, the scenario model and the interactive code |
| `Content/essay-final.md` | The essay text in one readable file |
| `Content/` (other files) | Outline, drafts, model specification and Python prototype |
| `index.html` | Redirects to the essay |

## Run it yourself

Open `forecast.html` in any browser; no install is needed. To reproduce the scenario numbers, run `python3 Content/model_prototype.py`.
